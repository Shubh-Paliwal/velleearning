# VelleEarning

A web-based earning platform developed using **Django** that connects users with earning opportunities through job listings and other opportunities. The platform provides an easy-to-use interface for users to explore opportunities while allowing administrators to manage the platform efficiently.

---

## Features

- User Registration & Login
- Secure Authentication
- Browse Earning Opportunities
- Job Listing Management
- Responsive User Interface
- Admin Dashboard
- Database Integration with SQLite

---

## Tech Stack

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/VellyEarning.git
```

### Navigate to the project

```bash
cd VellyEarning
```

### Create a virtual environment

```bash
python -m venv .venv
```

### Activate the virtual environment

**Windows**

```bash
.venv\Scripts\activate
```

**Linux / macOS**

```bash
source .venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
